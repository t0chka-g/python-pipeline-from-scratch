## Часть 1. Пишем парсер своими руками

### 1. Рассматриваем HTML

HTML — язык разметки страницы: он описывает элементы и их вложенность. Откройте `data/raw/books.html` в текстовом редакторе и найдите `product_pod`. Упрощённый пример карточки:

```html
<article class="product_pod">
  <h3><a href="catalogue/example/index.html" title="Название книги">Название</a></h3>
  <p class="price_color">£51.77</p>
  <p class="instock availability">In stock</p>
</article>
```

Теги `<article>` и `</article>` обозначают начало и конец элемента. Внутри него находятся вложенные `h3`, `a` и `p`. `class`, `href`, `title` — атрибуты, то есть дополнительные свойства: классы помогают выбрать элемент, `href` хранит ссылку, `title` — полное название. В реальном HTML могут быть пробелы, переносы и другие вложенные элементы: это нормально. Посмотрите именно исходный HTML в редакторе или в браузере через «Просмотреть исходный код», затем найдите похожие карточки.

**CSS-селектор** описывает, какие элементы найти. `article.product_pod` означает тег `article` с классом `product_pod`; `h3 a` — тег `a` внутри `h3`; `p.price_color` — абзац с указанным классом. Одна карточка содержит все поля: ищем сначала карточки, затем поля внутри каждой, чтобы не смешать разные книги.

### 4. Пишем программу

Создайте `src/parse_books.py`. Введите полный код ниже, сохраняя отступы; затем сравните каждый блок с объяснением после примера. Этот код использует тот же путь проекта независимо от каталога запуска. Первая часть читает HTML, цикл собирает данные, последняя сохраняет JSON.

```python
from pathlib import Path
import json
import sys
from urllib.parse import urljoin, urlsplit

from bs4 import BeautifulSoup


BASE_URL = "https://books.toscrape.com/"
PROJECT_DIR = Path(__file__).resolve().parent.parent
HTML_FILE = PROJECT_DIR / "data" / "raw" / "books.html"
JSON_FILE = PROJECT_DIR / "data" / "processed" / "books.json"


def main():
    try:
        html = HTML_FILE.read_text(encoding="utf-8")
    except FileNotFoundError:
        print("HTML не найден. Сначала запустите: python src/main.py", file=sys.stderr)
        return 1
    except (OSError, UnicodeError) as error:
        print(f"Не удалось прочитать HTML: {error}", file=sys.stderr)
        return 1

    soup = BeautifulSoup(html, "html.parser")
    cards = soup.select("article.product_pod")
    if not cards:
        print("Карточки книг не найдены. Проверьте HTML и селектор.", file=sys.stderr)
        return 1

    books = []
    for number, card in enumerate(cards, start=1):
        link = card.select_one("h3 a")
        price = card.select_one("p.price_color")
        availability = card.select_one("p.availability")

        if not link or not link.get("title") or not link.get("href") or not price or not availability:
            print(f"Карточка {number}: отсутствует название, ссылка, цена или наличие.", file=sys.stderr)
            return 1

        title = link.get("title").strip()
        href = link.get("href").strip()
        price_text = price.get_text(strip=True)
        availability_text = availability.get_text(strip=True)
        if not title or not href or not price_text or not availability_text:
            print(f"Карточка {number}: одно из полей пустое.", file=sys.stderr)
            return 1

        try:
            url = urljoin(BASE_URL, href)
            parsed_url = urlsplit(url)
            if parsed_url.scheme not in ("http", "https") or not parsed_url.netloc:
                raise ValueError("ожидалась HTTP-ссылка")
        except ValueError as error:
            print(f"Карточка {number}: некорректная ссылка: {error}", file=sys.stderr)
            return 1

        books.append({
            "title": title,
            "price": price_text,
            "availability": availability_text,
            "url": url,
        })

    try:
        JSON_FILE.parent.mkdir(parents=True, exist_ok=True)
        with JSON_FILE.open("w", encoding="utf-8") as file:
            json.dump(books, file, ensure_ascii=False, indent=2)
    except OSError as error:
        print(f"Не удалось сохранить JSON: {error}", file=sys.stderr)
        return 1

    print(f"Найдено книг: {len(books)}. JSON сохранён в {JSON_FILE}")
    return 0


if __name__ == "__main__":
    sys.exit(main())
```

Разберём последовательность небольшими шагами:

1. `HTML_FILE.read_text(encoding="utf-8")` читает HTML в строку `html`. Если файла нет, программа сообщает, что нужно запустить первый урок. `PROJECT_DIR` строится от расположения скрипта, как и путь в уроке 1.
2. `BeautifulSoup(html, "html.parser")` разбирает строку; `soup.select("article.product_pod")` возвращает все найденные карточки. Если список пуст, код сообщает об этом вместо сохранения пустого результата.
3. Для каждой карточки `select_one("h3 a")`, `select_one("p.price_color")` и `select_one("p.availability")` находят нужные элементы. Проверки останавливают программу, если элемент, атрибут или текст отсутствует. Номер карточки поможет найти проблему.
4. `get("title")` и `get("href")` получают атрибуты, `get_text(strip=True)` — текст цены и наличия. `urljoin(BASE_URL, href)` превращает относительную ссылку в абсолютную. Далее проверяем схему и наличие имени сервера.
5. `books.append({...})` добавляет словарь с полями `title`, `price`, `availability`, `url` в список. Цена остаётся строкой с символом валюты, без вычислений.
6. Создаём `data/processed/` при необходимости и записываем список через `json.dump`. Сообщение указывает количество книг и полный путь результата. При ошибке проверки карточки новый JSON не записывается; ранее сохранённый файл может остаться, поэтому ориентируйтесь на сообщение последнего запуска.

## Часть 2. Подробный разбор кода

- `from bs4 import BeautifulSoup` импортирует класс из установленной библиотеки; `json`, `sys`, `pathlib` и `urllib.parse` входят в Python. `BASE_URL` — базовый адрес главной страницы, `HTML_FILE` и `JSON_FILE` — объекты путей `Path`.
- `try` и `except` обрабатывают предсказуемые ошибки чтения и записи. `FileNotFoundError` отдельно даёт инструкцию по скачиванию, `UnicodeError` сообщает о проблеме декодирования. `file=sys.stderr` отправляет ошибку в поток ошибок, а `return 1` обозначает неуспех. Подробнее о функциях и ошибках — в [уроке 1](01-http-requests.md#часть-2-разбираемся-в-коде).
- `BeautifulSoup(html, "html.parser")` строит дерево элементов из текста с помощью встроенного парсера Python. Дерево отражает вложенность тегов и позволяет искать внутри отдельных элементов.
- `select(...)` возвращает список всех совпадений по CSS-селектору; `select_one(...)` — первое совпадение или `None` (отсутствие значения). Безопасно проверить результат **до** вызова его методов. Для сравнения: `soup.find("article", class_="product_pod")` находит первый такой тег или `None`, а `soup.find_all("article", class_="product_pod")` — все. Здесь в рабочем коде используются CSS-селекторы; `find` и `find_all` — другой способ поиска.
- `for number, card in enumerate(cards, start=1):` перебирает карточки по одной и нумерует их с единицы. Тело цикла имеет отступ; `return 1` прерывает всю функцию при ошибке, а не пропускает карточку незаметно.
- `link.get("title")` и `link.get("href")` обращаются к атрибутам HTML; если атрибута нет, возвращается `None`. Сначала проверяем `link`, затем атрибуты: `or` прекращает проверку, когда условие уже истинно. `strip()` удаляет пробелы по краям строки, а `.get_text(strip=True)` собирает текст элемента и убирает окружающие пробелы. Дополнительная проверка отсекает и строки, состоящие только из пробелов.
- `books = []` создаёт список, а `{ "title": title, ... }` — словарь, где текстовые ключи связаны со значениями. `append` добавляет один словарь в список. Имена полей одинаковы у всех записей.
- `urljoin(BASE_URL, href)` разрешает относительный адрес относительно главной страницы. `urlsplit` разбирает итоговый URL; проверка `scheme` и `netloc` отсекает отсутствующий хост или неподходящую схему. `ValueError` обрабатывает некорректный адрес. База подходит именно HTML главной страницы из урока 1; для файла другой страницы нужно передать адрес именно этой страницы как базу.
- `mkdir(parents=True, exist_ok=True)` создаёт недостающие каталоги. `with JSON_FILE.open("w", encoding="utf-8") as file:` открывает файл на запись с перезаписью и автоматически закрывает его. `json.dump(books, file, ensure_ascii=False, indent=2)` записывает данные в JSON: `indent=2` добавляет отступы, `ensure_ascii=False` сохраняет символы вроде `£` непосредственно. UTF-8 — кодировка, задающая представление символов в байтах; используем её и при чтении HTML, и при записи JSON.
- `len(books)` возвращает число записей. `return 0` и `sys.exit(main())` сообщают системе об успешном завершении. При ошибке сохранения возможен частично записанный файл; проверяйте сообщение программы.

## Часть 3. Практика и структура данных

```text
HTML-файл → BeautifulSoup → CSS-селекторы → словари Python → JSON-файл
```

HTML описывает структуру страницы для отображения, а JSON — текстовый формат обмена данными. Структурирование отделяет нужные поля от разметки. Список словарей удобен тем, что можно перебрать книги и обратиться к каждому полю по одинаковому имени. Например, первая запись файла выглядит примерно так:

```json
[
  {
    "title": "A Light in the Attic",
    "price": "£51.77",
    "availability": "In stock",
    "url": "https://books.toscrape.com/catalogue/a-light-in-the-attic_1000/index.html"
  }
]
```

В действительном результате записей обычно больше. Относительный `catalogue/...` сам по себе не указывает сайт; абсолютный `https://books.toscrape.com/catalogue/...` содержит схему и сервер. Если сайт изменит теги, классы или атрибуты, селектор может перестать находить элементы или найти другие данные. Программа сообщает об отсутствии и пустых полях, но не гарантирует обнаружение всех смысловых изменений: сверяйте JSON с HTML.

Чтобы проверить, что JSON читается обратно, выполните из корня:

```bash
python -c "import json; from pathlib import Path; books = json.loads(Path('data/processed/books.json').read_text(encoding='utf-8')); print(len(books), books[0])"
```

Ожидается количество записей и первый словарь. Ошибка укажет на отсутствие файла, пустой список или некорректный JSON.

## Часть 4. Самостоятельные задания

1. **Рейтинг.** Условие: извлеките рейтинг из класса элемента `p.star-rating` каждой карточки и добавьте поле в словарь. Подсказка: `element.get("class", [])` возвращает список классов; найдите среди них `One`, `Two`, `Three`, `Four` или `Five`. Ожидается текст рейтинга у каждой книги. Критерии: рейтинг соответствует исходной карточке и отсутствие класса не вызывает непонятную ошибку.
2. **Наличие.** Условие: оставьте в результате только доступные книги и выведите их количество. Подсказка: сравните очищенный `availability_text` с `In stock`; данные на других страницах могут отличаться. Ожидается список доступных книг и число. Критерии: число совпадает с длиной списка, недоступные записи не попадают в JSON; проверьте также на локальном примере с другой строкой наличия.
3. **Пять самых дорогих.** Условие: дополнительно выведите пять книг с наибольшей ценой. Подсказка: для формата этого сайта проверьте, что цена начинается с `£`, затем преобразуйте остаток через `Decimal` из стандартного модуля `decimal`; обработайте `InvalidOperation` и сообщите о неверной цене. Отсортируйте копию списка с `sorted(..., key=..., reverse=True)`. Ожидаются до пяти названий и цен по убыванию. Критерии: порядок верен, исходная строка цены сохраняется, некорректная цена не приводит к непонятному traceback. Это учебное преобразование для известного формата, а не универсальный разбор валют.

## Troubleshooting

Сначала посмотрите сообщение последнего запуска, откройте `data/raw/books.html` в редакторе и найдите `product_pod`. Сравните теги и атрибуты одной полной карточки с селекторами. Для исследования можно в отдельном Python-фрагменте вывести `len(soup.select("article.product_pod"))` и `print(soup.select_one("article.product_pod"))`; не меняйте исходный HTML без сохранения его копии.

| Симптом | Причина | Что проверить и сделать |
| --- | --- | --- |
| `ModuleNotFoundError: No module named 'bs4'` | Библиотека не установлена в используемое окружение. | Активируйте `.venv` и выполните `python -m pip install -r requirements.txt`; убедитесь, что запускаете Python этого окружения. |
| HTML не найден | Первый этап ещё не запущен или файл перемещён. | Выполните `python src/main.py` из корня проекта с интернетом и проверьте `data/raw/books.html`. |
| Селектор ничего не возвращает | Выбран неправильный тег или класс, либо разметка сайта изменилась. | Найдите карточку в сохранённом HTML, сравните классы и вложенность с селектором; проверьте, что файл действительно содержит страницу каталога. |
| `AttributeError` у отсутствующего элемента | Метод вызван у `None` до проверки. | Найдите строку с вызовом, выведите результат `select_one` и добавьте проверку перед использованием. В исходном коде такие элементы проверяются. |
| Ссылка ведёт не туда | Ошибочны базовый адрес или `href`; сохранён HTML другой страницы. | Сравните `href` с исходным HTML. Для `urljoin` используйте URL страницы, с которой сохранён HTML; проверьте итоговый адрес. |
| `UnicodeDecodeError` или вместо `£` непонятные символы | HTML или JSON открыт с неверной кодировкой, либо файл был повреждён. | Проверьте объявление кодировки в HTML и откройте файлы как UTF-8. Для исходной страницы заново скачайте HTML; не игнорируйте ошибки декодирования. |
| JSON пустой или записи неполные | Мог использоваться старый файл, изменённый парсер или разметка. | Проверьте сообщение последнего запуска и сравните поля с HTML. Исходный код прекращает работу до записи при отсутствии карточек или обязательных данных, но старый JSON может остаться. |

## Словарь

- **Тег** — обозначение элемента HTML; **атрибут** — его свойство, например `href`.
- **CSS-селектор** — выражение для выбора элементов по тегам, классам и вложенности.
- **Дерево HTML** — представление элементов и их вложенности.
- **Список** — упорядоченная коллекция значений; **словарь** — набор пар ключ–значение.
- **JSON** — текстовый формат представления и обмена данными.
- **Относительный URL** разрешается относительно базы; **абсолютный URL** содержит полный адрес.
- **UTF-8** — способ кодирования Unicode-символов в байты.
