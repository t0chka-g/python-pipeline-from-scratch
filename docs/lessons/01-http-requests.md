# Урок 1. Python, Git, HTTP и Requests

На этом уроке мы скачиваем исходный HTML главной страницы учебного книжного сайта. Мы пока не извлекаем из него названия или цены.

## Из чего состоит проект

Python-проект — это файлы программы и инструкции для её запуска. В нашем проекте `src/main.py` содержит код, а `docs/lessons/` — материалы уроков. `README.md` знакомит с проектом и помогает начать работу.

Git хранит историю изменений файлов в виде коммитов — сохранённых снимков проекта. Ветка позволяет вести работу отдельно от других изменений. Файл `requirements.txt` перечисляет внешние зависимости: здесь это библиотека Requests с зафиксированной версией. Зависимость — чужой код, который наша программа использует.

Виртуальное окружение `.venv` — отдельное место для установленных библиотек проекта. Оно помогает разным проектам использовать разные версии библиотек. `.gitignore` сообщает Git, какие создаваемые файлы не нужно добавлять в историю: окружение, кеш Python и скачанные HTML-файлы. Сам файл `.gitignore` хранится в Git.

## Как страница попадает к нам

HTTP — набор правил обмена данными между клиентом и сервером. Клиент отправляет запрос, а сервер отвечает. Здесь клиент — наша программа, сервер — сайт с книгами. URL `https://books.toscrape.com/` указывает адрес ресурса; `https` означает защищённое соединение. Метод GET просит сервер предоставить ресурс, как просьба показать страницу в браузере.

HTTP-ответ содержит статус-код, заголовки с дополнительными сведениями и тело — в нашем случае HTML. Например, статус 200 означает успешный ответ, а 404 — что ресурс не найден. Проверка статуса важна: иначе можно сохранить страницу с сообщением об ошибке, приняв её за нужную страницу.

## Как работает программа

Requests — библиотека для HTTP-запросов. Посмотрите на `src/main.py`:

- `URL` хранит адрес сайта. `OUTPUT` строит путь от расположения файла программы к `data/raw/books.html`, поэтому путь не зависит от текущего каталога запуска.
- `requests.get(URL, timeout=10)` отправляет GET-запрос. `timeout` ограничивает ожидание сетевых операций в секундах; это не общий лимит времени всей загрузки.
- `response.raise_for_status()` вызывает ошибку для ответов со статусом 4xx или 5xx. Только после этой проверки программа сохраняет данные.
- `OUTPUT.parent.mkdir(parents=True, exist_ok=True)` создаёт недостающие папки; если они уже есть, ошибки не будет.
- `OUTPUT.write_bytes(response.content)` записывает байты тела ответа без изменения кодировки. При повторном успешном запуске файл перезаписывается.
- `try` и `except` позволяют вывести понятное сообщение при таймауте, ошибке HTTP, другой ошибке запроса или ошибке записи. При ошибке программа завершится с кодом 1, при успехе — с кодом 0. Ранее скачанный файл при сетевой ошибке не удаляется.
- `if __name__ == "__main__":` запускает `main()` при непосредственном запуске файла; `sys.exit` передаёт её результат операционной системе.

Без таймаута ожидание сети может затянуться. Ошибки возможны, например, если интернет недоступен или сервер вернул 404; их обработка помогает понять, почему результат не получен.

## Установка и запуск

Установите Python 3 с официального сайта Python, откройте терминал в корне проекта (где лежит `requirements.txt`) и выполните команды. Для установки зависимости и загрузки страницы нужен интернет.

Windows PowerShell:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python src/main.py
```

Если PowerShell запрещает запуск скрипта активации, можно обойтись без активации:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe src/main.py
```

Linux/macOS:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python src/main.py
```

После работы активированное окружение можно отключить командой `deactivate`.

## Проверка результата

При успехе программа выведет путь к сохранённому файлу `data/raw/books.html`. Откройте его в редакторе: в исходном HTML должны встречаться `Books to Scrape` и HTML-теги. Это исходный код страницы, а не готовая таблица книг. Повторите запуск: сообщение снова появится, а файл обновится. Если вы получили ошибку, проверьте интернет и доступность сайта; старый файл сам по себе не доказывает успех последнего запуска.

## Самостоятельные задания

1. Найдите в HTML заголовок страницы и сравните его с вкладкой сайта в браузере.
2. Временно замените URL на несуществующий путь на том же сайте и посмотрите на сообщение об HTTP-ошибке. Затем верните исходный адрес.
3. Измените текст сообщения об успешном сохранении, запустите программу и проверьте результат. Верните текст или сохраните своё изменение отдельным коммитом.
